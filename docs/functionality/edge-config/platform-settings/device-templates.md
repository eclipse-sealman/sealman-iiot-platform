# Device templates

> **Warning**
> This setting page is available, but the selected templates are currently not used anywhere in the platform.
> It is intended for future developments where template selection will be used to filter templates that can be applied to devices.

The device templates page lets you select which Smart EMS templates are available at platform level.

The page has two lists:

- **Selected Templates**: Templates currently selected for the platform
- **Available Templates**: Templates retrieved from Smart EMS that can be selected

## Open device templates

1. Open **Settings** from the main navigation
2. Click **Device Templates** in the settings menu
3. The **Device Templates** page opens

## Select templates

To add a template to the selected list:

1. In **Available Templates**, locate the template you want to use
2. Click the **+** action on that template

The template moves to **Selected Templates**.

## Remove templates

To remove a template from the selected list:

1. In **Selected Templates**, locate the template you want to remove
2. Click the **x** action on that template

The template is removed from **Selected Templates** and returns to **Available Templates**.

## Search templates

Both template lists include a search field:

- Use **Search selected...** to filter templates already selected
- Use **Search available...** to filter templates available from Smart EMS

Search helps when the template catalog is large.

## Scope and behavior

Device template selection is global and applies to the whole platform.

At this stage, selected templates are stored for future use and do not affect current device workflows.
